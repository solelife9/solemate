# 브랜드 커버리지

> 어떤 브랜드가 앱에 들어와 있고 어디까지 채워졌는지 추적하는 운영 문서
> (docs/shoes-spec.md §9). 소스별 함정은 같은 문서 §10 에 있다.

## 채우는 규칙

- **읽은 것만 넣는다.** 기억으로 브랜드를 추가하지 않는다. 어느 페이지에서 읽었는지
  근거를 남길 수 없으면 넣지 않는다.
- **등록 모델 수**는 실제 카탈로그에서 센 값이다(추정 금지).
- **마지막 확인일**은 그 브랜드의 라인업을 실제로 대조한 날이다. 표를 손댄 날이 아니다.
- 기준선은 **한국에서 실제로 팔리는 것**이다 — 브랜드 한국 공식몰과 국내 편집샵
  (굿러너컴퍼니)에 있는 러닝화는 앱에도 있어야 한다.
- **없는 신발은 지운다.** 판정 기준은 아래 '유령 항목' 절.

## 지금 쓰는 소스

**브랜드 공식몰이 1순위다.** 소매점·아카이브는 공식몰에 없는 것만 메운다.
기준 사이즈를 값에 적어 주는 곳이 가장 좋다 — 무게는 기준을 모르면 비교에 못 쓴다.

### 기준 사이즈까지 적어 주는 곳 (최상급)

| 소스 | 형식 | 비고 |
|---|---|---|
| **미즈노 글로벌**(usa.mizuno.com) | `weight: 9.3 oz (Size 9)` · `stack: 29mm (FF)• 39mm (H)` | 상품 메타필드. 남녀가 한 페이지에 있어 사이즈로 가른다 |
| **나이키 코리아**(nike.com/kr) | `무게: 약 325g(280mm 기준)` · `오프셋: 10mm` | 스택은 설명 문장에("앞꿈치에서 36mm이고 뒤꿈치에서 46mm") |
| **뉴발란스 아카이브** | `Listed weight reflects one shoe (7W or 9.5M)` · `288 grams` | 9.5M = 275mm |
| **데카트론 코리아** | 구조화 데이터에 **카본 유무**까지 | Kiprun 전용이지만 가장 완전하다 |

### 브랜드 공식몰

| 소스 | 비고 |
|---|---|
| **아디다스 5개국**(kr·us·gb·ie·au) | 나라마다 재고가 다르다 — 울트라부스트 5 는 한국·미국엔 없고 **영국에 21개** 있다. ⚠ 적힌 기준 사이즈는 **로케일 상용구**다(같은 275g 이 미국 `size 9` / 영국 `size UK 8.5`) |
| **살로몬 글로벌** | 무게·드롭·앞뒤 스택. 한국 로케일 없음(총판 판매) |
| **브룩스 글로벌** | 국내몰은 현행 재고만(고스트 17·맥스 3까지). 스택은 안 준다 |
| **On 코리아** | Nuxt 페이로드가 HTML 안에. **남녀 무게가 필드로 분리**(weightMen/weightWomen) |
| 브룩스·써코니·미즈노 한국몰 | 무게에 기준 사이즈 명시 |

### 아카이브 (단종 모델 복구)

살아 있는 사이트가 막혔거나 재고에서 내려간 모델을 되살린다.
**브랜드마다 함정이 정반대라 캡처 고르는 순서가 다르다** — docs/shoes-spec.md 참조.

| 소스 | 캡처 순서 | 비고 |
|---|---|---|
| Running Warehouse(US) | 최신 먼저 | 기존 200여 켤레의 원본. 브랜드당 CDX 한 번으로 경로 수집 |
| **아디다스** | **오래된 것 먼저** | 내려간 뒤 캡처는 4KB 껍데기. 옛 표기는 `Weight: 333 g (size UK 8.5)` |
| **나이키** | **최신 먼저** | 최근에야 스펙을 싣기 시작(2023년 캡처엔 없고 2025년엔 있다) |
| **아식스** | **오래된 것 먼저** | 살아 있는 사이트는 전 로케일 Akamai 차단. 사이트맵으로 URL 을 얻어 아카이브에 넣는다 |
| **호카** | 최신 먼저 | 살아 있는 사이트는 DataDome. ⚠ 접두어가 `-mid-gtx`(부츠)를 문다 |
| **브룩스·On·뉴발란스** | 경로 접두어 질의 | 정규식 필터 질의는 CDX 가 90초를 넘겨 죽는다 |

### 보조

- **굿러너컴퍼니** — 국내 편집샵. 상세 이미지의 스펙 카드. ⚠ 카드가 **상품(성별)별**
- **아웃오브올** — 965개 중 스펙 텍스트가 있는 건 76개뿐(소진)
- **다나와** — 힐드롭만. 무게는 기준 미표기라 쓰지 않는다

## 접근 불가로 확인한 소스 (2026-08-01 재확인)

⚠ **이 목록은 낡기 쉽다.** 이전 판에는 나이키·아디다스·브룩스·뉴발란스·살로몬·호카가
전부 '막힘'으로 적혀 있었는데, 다시 해 보니 **여섯 곳 다 뚫렸다.** 막혔다고 적힌 이유가
'차단'이 아니라 '요청이 부실해서'이거나, 경로를 잘못 짚었기 때문인 경우가 많다.

| 소스 | 실제 상태 |
|---|---|
| `newbalance.com` | Akamai 차단 — **아카이브로 우회 가능** |
| `asics.com`(전 로케일) | Akamai 차단 — **사이트맵 + 아카이브로 우회 가능** |
| `hoka.com` | DataDome — **아카이브로 우회 가능** |
| `kr.puma.com` · `us.puma.com` | 열리지만 **푸마가 스펙을 아예 공표하지 않는다** |
| `nbkorea.com` | 1KB 플레이스홀더 — 몰 자체가 없다 |
| `onyourmark-running.com` · `mabseoul.com` | 상세가 사진 한 장 |
| 무신사 · 29CM | 판매자 입력 스펙이라 쓰지 않는다 |

**나이키는 막힌 곳이 아니다.** robots.txt 가 막는 건 `*/p/` 인데 나이키의 상품 경로는
`/t/` 다. `/kr/en/`(영문 한국)만 금지된다. 상품 사이트맵도 공개한다.

## 유령 항목 — 없는 신발은 지운다

이번에 **9켤레**를 지웠다(624 → 615). 전부 제품으로 나온 적이 없거나 중복이었다.

| 삭제 | 근거 |
|---|---|
| 울트라부스트 23·24·25 | 아디다스 라인은 22 → 라이트 → 5 → 5X |
| 나이키 보메로 19 | 라인은 16·17·18 → 플러스/프리미엄/로암 |
| 나이키 인빈시블 4 | 아카이브에 2·3 만 |
| 나이키 인피니티 런 5 | InfinityRN 은 4 까지 |
| 뉴발란스 880 v16 | 아카이브 v15=40건 / v16=0건 |
| On 클라우드서퍼 3 | 버전은 `cloudflyer-5-<코드>` 처럼 하이픈으로 붙는데 `cloudsurfer-3-*` 가 없다 |
| `nike-react-infinity-run-3` | `nike-infinity-run-3` 과 값·별칭이 완전히 같은 **중복 등록** |

**판정은 세 겹을 다 통과해야 한다:** 현행 한국 사이트맵 0 · 현행 글로벌 사이트맵 0 ·
아카이브 0건. 형제 버전은 수십 건씩 잡히므로(보메로 18=50건) '이것만 없는' 게 근거다.

주의할 것 둘:
- **비어 있다고 유령이 아니다.** 스펙이 네 항목 다 빈 문서가 76개지만 대부분 단종된
  실존 모델이다(윈플로 9·10·11 · 스피드크로스 5 · 웨이브 라이더 27). 번호가 라인
  **뒤쪽**이면 그냥 옛 모델이다. 유령은 **최신 버전보다 번호가 높은** 쪽에서 나온다.
- **404 만으로 판정하지 마라.** On 은 실제 URL 이 상품코드를 포함해서, 슬러그만으로
  찍은 404 는 실존 모델(클라우드서퍼 2)에도 똑같이 난다.
- **규칙이 짚어도 확인 없이 지우지 마라.** 나이키 인피니티 런 4 는 규칙에 걸렸지만
  실존한다 — `React Infinity Run` 이 `InfinityRN` 으로 **개명**됐을 뿐이다.

## 못 채운 이유 (주력 본모델 27켤레)

- **나이키 6** — 인빈시블 2 · 스트럭처 24 · 줌플라이 4·5 · 베이퍼플라이 2 ·
  인피니티 런 4. 나이키가 **스펙을 싣기 시작하기 전** 페이지라 아카이브에도 숫자가 없다.
- **아디다스 4** — 아디오스 프로 Evo 3 · 프라임 X Evo · 수퍼노바 스트라이드 ·
  울트라부스트 라이트. **아디다스가 그 상품에 스펙 블록을 안 실었다**(독일몰까지 확인).
- **호카 3** — 본다이 X 는 캡처가 하나뿐인데 재생이 20바이트 오류, 린콘 4 · EVO
  스피드고트는 2024년 모델이라 DataDome 도입 후 **캡처 자체가 없다**.
- **푸마 2** — 브랜드가 무게·드롭을 아예 공표하지 않는다(한국·미국 공홈 둘 다).
- **나머지 12** — 단종 + 아카이브 스냅샷이 없거나 406 오류다(미즈노 웨이브 라이더 27 은
  스냅샷이 하나뿐인데 그게 406 이다).

빈칸은 비워 둔다. 비교 화면은 값이 없는 축을 조용히 빼므로 앱은 멀쩡하고,
"모른다"를 그럴듯한 숫자로 메우지 않는다(Truth only).

## 값 검증

- `npm run validate-shoes` — 한 신발 **안의** 모순(스택 − 드롭 불일치, 범위 밖)
- `node scripts/audit-shoes.mjs` — **다른 신발과 견줘야** 보이는 것:
  카테고리 대비 무게 · 스택 대비 무게 · 변형 vs 본모델 · 인접 세대 점프 ·
  값이 완전히 같은 다른 신발 · 물리적 범위

두 번째가 실제로 오류를 잡았다: 페가수스 트레일 4·5 GTX 가 본모델보다 **가벼웠고**
(방수막이 들어가면 반드시 더 무겁다), 나이키 인피니티 런 3 이 중복 등록돼 있었다.

⚠ 감사의 '값이 완전히 같은 다른 신발' 경고는 **대부분 우연이다.** 4항목이 다 있는
435켤레가 서로 다른 조합 410개를 쓰는데 스택 조합은 159종뿐이고 무게도 102종에
몰려 있다. 이 밀도면 25건 충돌은 확률적으로 나올 수치다.
