# 브랜드 커버리지

> 어떤 브랜드가 앱에 들어와 있는지 추적하는 표. 카탈로그가 낡는 걸 막는 운영 문서다
> (docs/shoes-spec.md §9).
>
> **이 표는 아직 비어 있다** — 이번 작업은 뼈대만 만들었다. 채울 때는 아래 규칙을 지킨다.

## 채우는 규칙

- **읽은 것만 넣는다.** 기억으로 브랜드를 추가하지 않는다. 어느 페이지에서 읽었는지
  근거를 남길 수 없으면 넣지 않는다.
- **등록 모델 수**는 실제 카탈로그에서 센 값이다(추정 금지).
- **마지막 확인일**은 그 브랜드의 라인업을 실제로 대조한 날이다. 표를 손댄 날이 아니다.
- 기준선은 **편집샵 입점 브랜드**로 잡는다 — 실제로 팔리는 것이 곧 사용자가 신는 것.

## 소스와 한계 (2026-07-29)

- 주 소스는 **Running Warehouse 제품 페이지**다. 모델별로 무게·힐/앞발 스택·드롭을
  한 자리에서 공표해 브랜드 간 비교가 가능하다. 브랜드 공식몰(Nike 등)은 봇 차단(403)으로
  읽지 못했다.
- **Under Armour** 는 Running Warehouse 가 러닝화를 취급하지 않아 모델명만 underarmour.com
  에서 확인했다. 스펙 14켤레 전부 미확인.
- **Kiprun** 은 kiprun.com 에 스펙 표기가 아예 없다. 모델명·용도만 확인. 검색 결과에만
  등장한 구형 모델명(KD900X·KS900 등)은 **페이지에서 읽지 못해 넣지 않았다.**
- 직전 세대 모델은 대부분 이름만 있고 스펙이 없다(소매점이 단종 모델 페이지를 내린다).
  '스펙없음' 열이 그 크기다.
