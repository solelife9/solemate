## A. App Store — 앱 개인정보(App Privacy)

### 1. 추적(Tracking)
- **이 앱은 사용자를 추적하지 않습니다.** (광고 식별자·데이터 브로커·크로스앱 추적 SDK 없음 → ATT 프롬프트 불필요)

### 2. 수집하는 데이터 (전부 "사용자에게 연결됨 / App Functionality" — 판매·광고 목적 0)

| 데이터 유형 | 세부 | 용도 | 연결됨? |
|---|---|---|---|
| **위치 - 정확한 위치** | 러닝 GPS 경로·거리·페이스 | 앱 기능(러닝 트래킹) | 예 |
| **건강 및 피트니스** | 심박(HealthKit 읽기), 워크아웃(쓰기), 케이던스·고도 | 앱 기능(러닝 분석·저장) | 예 |
| **연락처 정보 - 이메일** | 소셜 로그인(구글·애플·카카오·네이버)에서 받은 이메일 | 앱 기능(계정 식별·로그인) | 예 |
| **사용자 콘텐츠 - 사진** | 러닝화·메달·기록증 사진(사용자 촬영/선택) | 앱 기능(신발 등록·기록) | 예 |
| **식별자 - 사용자 ID** | Firebase Auth UID | 앱 기능(클라우드 동기화·계정) | 예 |
| **진단 - 충돌 데이터** | Crashlytics 크래시 로그 | 앱 기능(안정성 개선) | 예* |

\* Crashlytics 는 UID 와 연결될 수 있어 보수적으로 "연결됨"으로 신고. 광고/분석 목적 아님.

### 3. 수집하지 않는 것 (설문에서 "아니오")
- 결제 정보(인앱결제 없음), 정확한 광고 식별자, 브라우징 기록, 연락처 목록, 검색 기록.
- 이름은 소셜 로그인의 표시이름(displayName)만 계정 표시용으로 보관 — 별도 수집 항목으로 신고할지는 선택(연락처 정보>이름으로 포함 가능, 보수적으로 포함 권장).

## B. Google Play — 데이터 보안(Data Safety)

### 수집 및 공유
- **데이터 공유(3자 제공): 없음.** (Firebase 는 처리자/백엔드이지 "공유" 대상 아님)
- **데이터 수집: 예** (아래). 전송 중 암호화(HTTPS/TLS): 예. 사용자 삭제 요청 경로: 예(앱 내 계정 삭제).

| 카테고리 | 항목 | 수집 | 목적 |
|---|---|---|---|
| 위치 | 정확한 위치 | 예 | 앱 기능 |
| 건강 및 피트니스 | 건강 정보(심박·운동) | 예 | 앱 기능 |
| 개인 정보 | 이메일, 이름(표시이름) | 예 | 계정 관리·앱 기능 |
| 사진 및 동영상 | 사진 | 예 | 앱 기능 |
| 앱 활동 | (러닝 기록 등 앱 내 데이터) | 예 | 앱 기능 |
| 앱 정보 및 성능 | 크래시 로그·진단 | 예 | 앱 기능(안정성) |
| 기기 또는 기타 ID | 사용자 ID(UID) | 예 | 앱 기능 |

- **⚠️ 백그라운드 위치**: 화면 꺼도 러닝 추적 → Play 정책상 **백그라운드 위치 권한 선언 양식 + 용도 시연 영상** 요구될 수 있음(콘솔에서 안내). 용도 = "러닝 중 화면을 꺼도 거리·경로를 계속 기록".
- **계정 삭제**: 앱 내(마이 → 계정) 삭제 경로 있음 + 웹 삭제 안내 URL 필요 시 keego-legal 에 추가.
