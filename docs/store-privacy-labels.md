## A. App Store — 앱 개인정보(App Privacy)

### 1. 추적(Tracking)
- **이 앱은 사용자를 추적하지 않습니다.** (광고 식별자·데이터 브로커·크로스앱 추적 SDK 없음 → ATT 프롬프트 불필요)

### 2. 수집하는 데이터 (**판매·광고 목적 0**. 마지막 두 행만 '분석' 목적·연결 안 됨, 나머지는 전부 "사용자에게 연결됨 / App Functionality")

| 데이터 유형 | 세부 | 용도 | 연결됨? |
|---|---|---|---|
| **위치 - 정확한 위치** | 러닝 GPS 경로·거리·페이스 | 앱 기능(러닝 트래킹) | 예 |
| **건강 및 피트니스** | 심박(HealthKit 읽기), 워크아웃(쓰기), 케이던스·고도 | 앱 기능(러닝 분석·저장) | 예 |
| **연락처 정보 - 이메일** | 소셜 로그인(구글·애플·카카오·네이버)에서 받은 이메일 | 앱 기능(계정 식별·로그인) | 예 |
| **사용자 콘텐츠 - 사진** | 러닝화·메달·기록증 사진(사용자 촬영/선택) | 앱 기능(신발 등록·기록) | 예 |
| **식별자 - 사용자 ID** | Firebase Auth UID | 앱 기능(클라우드 동기화·계정) | 예 |
| **진단 - 충돌 데이터** | Crashlytics 크래시 로그 | 앱 기능(안정성 개선) | 예* |
| **검색 기록(Search History)** | 러닝화 등록 화면에서 **결과가 0건인 검색어**(`search_misses`) | 앱 기능(러닝화 목록의 누락 모델 파악·보강) | 예** |
| **사용자 콘텐츠 - 기타 사용자 콘텐츠** | 이용자가 입력한 러닝화 브랜드·모델명(`shoe_requests` — '내 신발이 없어요' 및 목록에 없는 신발 직접 추가) | 앱 기능(러닝화 목록 보강) | 예** |
| **사용 데이터 - 제품 상호작용** | 제품 계측 이벤트 10종 — 온보딩 단계, 첫 신발 등록, 러닝 시작/저장/폐기, 권한 수락 여부, 로그인 제공자, 동기 실패, 크래시 복구, 신발 은퇴 (`lib/productAnalytics.ts`) | **분석** + 앱 기능(개선) | 아니오*** |
| **식별자 - 기기 ID** | Firebase Analytics 앱 인스턴스 ID(SDK 자동 생성) | 분석 | 아니오*** |

\* Crashlytics 는 UID 와 연결될 수 있어 보수적으로 "연결됨"으로 신고. 광고/분석 목적 아님.

\*\* 두 항목 모두 문서에 `userId`(Firebase UID)가 함께 저장되므로 **"사용자에게 연결됨"** 으로
신고한다(`services/shoes.ts` `logSearchMiss`/`requestShoe`). 다른 이용자에게 공개되지 않으며
(Firestore 규칙에서 읽기 전면 차단, 생성만 허용) 광고·판매 목적이 아니다.

\*\*\* Analytics 두 항목은 **"연결 안 됨"** 으로 신고한다 — `lib/productAnalytics.ts` 가
`setUserId` 를 쓰지 않아 계정(UID)과 행동 로그를 잇지 않기 때문이다. 파라미터는 열거값과
버킷뿐이라 자유 텍스트(신발 모델명·메모·닉네임)나 정확한 거리·페이스는 보내지 않는다.
**추적(Tracking)은 여전히 "아니오"** — IDFA 를 쓰지 않고 AdSupport 도 링크돼 있지 않다.

- ~~제품 사용 계측(Analytics)~~ → **정정(2026-08-02)**: 초안의 "Analytics SDK 0 · Firebase
  Analytics 미사용"은 오기다. 위 표에 **제품 상호작용 · 기기 ID** 로 신고한다(상단 정정 주석 참조).

## B. Google Play — 데이터 보안(Data Safety)

### 수집 및 공유
- **데이터 공유(3자 제공): 없음.** (Firebase 는 처리자/백엔드이지 "공유" 대상 아님)
- **데이터 수집: 예** (아래). 전송 중 암호화(HTTPS/TLS): 예. 사용자 삭제 요청 경로: 예(앱 내 계정 삭제).

| 카테고리 | 항목 | 수집 | 목적 |
|---|---|---|---|
| 위치 | 정확한 위치 | 예 | 앱 기능 |
| 건강 및 피트니스 | 건강 정보(심박·운동) | 예 | 앱 기능 |
| 개인 정보 | 이메일, 이름(표시이름) | 예 | 계정 관리·앱 기능 |
| 사진 및 동영상 | 사진 | 예 | 앱 기능 |
| 앱 활동 | (러닝 기록 등 앱 내 데이터) | 예 | 앱 기능 |
| 앱 활동 | **앱 내 검색 기록**(결과 0건인 러닝화 검색어) | 예 | 앱 기능(러닝화 목록 보강) |
| 앱 활동 | **기타 사용자 생성 콘텐츠**(이용자가 입력한 러닝화 브랜드·모델명) | 예 | 앱 기능(러닝화 목록 보강) |
| 앱 활동 | **앱 상호작용**(제품 계측 이벤트 10종 — 온보딩·러닝·권한·로그인 퍼널) | 예 | **분석**(서비스 개선) |
| 앱 정보 및 성능 | 크래시 로그·진단 | 예 | 앱 기능(안정성) |
| 기기 또는 기타 ID | 사용자 ID(UID) · **Analytics 앱 인스턴스 ID** | 예 | 앱 기능 · 분석 |

- **⚠️ 백그라운드 위치**: 화면 꺼도 러닝 추적 → Play 정책상 **백그라운드 위치 권한 선언 양식 + 용도 시연 영상** 요구될 수 있음(콘솔에서 안내). 용도 = "러닝 중 화면을 꺼도 거리·경로를 계속 기록".
- **계정 삭제**: 앱 내(마이 → 계정) 삭제 경로 있음 + 웹 삭제 안내 URL 필요 시 keego-legal 에 추가.
