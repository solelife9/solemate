**러닝 — 정확하게**
· GPS 러닝 트래킹(칼만 필터 보정), 자동 일시정지
· 400m 트랙 모드 — 랩 자동 카운트

· Apple 건강 연동(심박·워크아웃 자동 저장), Apple Watch 단독 러닝

**러닝화 — 수명을 지키다**
· 신발별 누적 거리·남은 수명·교체 예측 — 근거와 정확도까지 함께
· 로테이션 — 신발을 번갈아 신어 더 오래
· 은퇴한 신발은 '러닝화 아카이브'에 영원히 — 함께한 거리 그대로

**기록 — 프리미엄 아카이브**
· 거리 PB(5K~풀코스), VO₂max 추정, 훈련 부하
· 국내 마라톤 대회 자동 감지 + 메달 아카이브
· 월간 랭킹, 업적과 랭크
