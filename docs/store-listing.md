## 설명
**Keego는 러닝과 러닝화를 하나로 관리하는 앱입니다.**

러닝화는 소모품입니다. 쿠셔닝이 닳은 신발은 충격을 무릎과 발목에 그대로 전달합니다. Keego는 달린 거리를 신발별로 자동 누적해 수명을 추적하고, 교체 시점이 오기 전에 알려드립니다.

**러닝 — 정확하게**
· GPS 러닝 트래킹(칼만 필터 보정), 자동 일시정지
· 400m 트랙 모드 — 랩 자동 카운트
· 오프라인 음성 안내, 거리별 스플릿·경사 보정 페이스
· Apple 건강 연동(심박·워크아웃 자동 저장)

**러닝화 — 수명 관리**
· 신발별 누적 거리·남은 수명·교체 예측
· 로테이션 추천 — 신발을 번갈아 신어 더 오래
· 은퇴한 신발은 '러닝화 아카이브'에 영원히

**기록 — 프리미엄 아카이브**
· 거리 PB(5K~풀코스), VO₂max 추정, 훈련 부하
· 마라톤 완주 자동 감지 + 메달 아카이브
· 월간 랭킹, 업적과 랭크

모든 숫자는 실제 기록입니다. 가짜 경쟁, 부풀린 성취는 없습니다.
