**잘못 켜져도 앱이 영구히 잠기지 않게** 만들었습니다. 차단 여부를 기기에 저장하지 않아서,

**재현:** `npm run test:rules`

### ✅ 🔴 심각한 결함 1건 발견 → 막았습니다

**기기를 같이 쓰면 앞사람 기록이 뒷사람 계정으로 올라갔습니다.**

```
A 로그인 → 사용 → A 로그아웃 → B 로그인
   → A 의 신발·러닝이 B 의 클라우드 계정으로 병합·업로드
   → B 가 A 의 GPS 이동 경로까지 봅니다. 앱 재시작도 필요 없습니다.
```

원인은 로컬 저장소에 **"이 데이터가 누구 것인지" 표시가 없었던 것**입니다. 로그아웃은
화면만 정리하고 기록은 그대로 두거든요(그건 원래 의도된 설계입니다 — 오프라인 보호).

**막은 방법:** 캐시에 주인을 적어두고, 동기화 직전에 "지금 로그인한 사람이 주인인가"를
확인합니다. 다르면 **업로드도 다운로드도 하지 않습니다.**

**일부러 '삭제'가 아니라 '차단'으로 했습니다.** 로그아웃할 때 기록을 지우는 게 간단하지만,
비행기모드에서 달린 기록이 아직 클라우드에 못 올라갔다면 그게 날아갑니다.
