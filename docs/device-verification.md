# 실기기 검증 체크리스트

> **왜 이 문서가 생겼나 (2026-08-12)**
>
> 민우님이 같은 러닝을 가민·아이폰·갤럭시로 동시에 재서 사진을 찍어 오시기 전까지
> **아무도 몰랐던 결함이 다섯 개** 나왔다. 그때 단위 테스트는 3,863개가 전부 초록이었다.
>
> 민우님 질문: *"근데 이런 걸 내가 일일이 다 찾아야 되는 거야 원래?"* — **아니다.**
>
> 그날 나온 것들의 공통점은 하나다: **코드는 맞는데 실제 기기에서 안 돌았다.**
> 단위 테스트가 볼 수 없는 자리들이다.
>
> | 결함 | 왜 못 잡았나 |
> |---|---|
> | 워치 누적 거리를 새 러닝이 물려받음 | 테스트가 **폰 쪽만** 봤다("워치 누적도 리셋된다"는 틀린 전제) |
> | 케이던스 1 spm | 08-05 "안드로이드 검증 완료"가 **거리만** 봤다 |
> | 갤럭시 거리 −5.7% | 08-10 거리 엔진 교체 검증이 **전부 합성 트레이스**였다 |
> | 폰 정지가 워치에 안 감 | WCSession 배달 경로에 **테스트가 아예 없었다** |
> | 워치 페이스 널뜀 | 마찬가지 |
>
> 그래서 규칙을 둘 만든다.
> **① "검증 완료"는 지표별로만 쓴다** — "안드로이드 검증"처럼 뭉뚱그리지 않는다.
> **② 하나라도 비면 완료가 아니다** — 모르는 칸은 '미확인'이라고 적는다(빈칸 금지).

---

## 어떻게 쓰나

러닝 한 번에 이 표를 채운다. **가민(또는 다른 기준 시계)을 같이 차고** 달리면 대부분의
칸이 한 번에 채워진다. 폰 두 대를 동시에 들고 달리면 플랫폼 차이까지 한 번에 잡힌다.

기록이 끝나면 **기록 상세 화면을 스크린샷**으로 남긴다 — 나중에 숫자를 다시 볼 수 있고,
안드로이드는 저장소를 뽑을 수 없어(릴리스 빌드·`allowBackup=false`) 화면이 유일한 창이다.

## 러닝 1회 체크리스트

### 거리·시간

| 항목 | 기준 | 판정 |
|---|---|---|
| 거리 | 가민 대비 **±2% 이내** | |
| 시간 | 가민 대비 **±5초 이내** | |
| 평균 페이스 | 거리·시간이 맞으면 자동으로 맞는다 | |
| 거리 진단 줄 | `사용 / 속도적분 / 위치` 세 값을 적어 둔다 | |

> 마지막 줄은 임시 진단이다(2026-08-12 도입). 08-10 에 거리 계산이 '위치 차분' →
> 'OS 속도 적분' 으로 바뀌었는데 실기기 대조가 없었다. **어느 쪽이 가민과 맞는지**
> 이 줄로 판가름낸다. 확정되면 줄을 지운다.

### 러닝 중 화면 (달리면서 본다)

| 항목 | 기준 | 판정 |
|---|---|---|
| 현재 페이스가 안 튄다 | 일정하게 달리면 **±10초/km 안에서 흔들림** | |
| 거리가 안 멈춘다 | 6초 이상 얼어붙지 않는다 | |
| 워치 현재 페이스 | 위와 같은 기준 | |
| 자동 일시정지 | 신호대기에 걸리고, 출발하면 3초 안에 풀린다 | |

> 민우님 원문: *"일정한 속도로 계속 달리면 페이스는 원래 그렇게 널뛰지 않잖아."*
> 맞다 — **튀면 러너가 아니라 측정이 틀린 것이다.**

### 센서

| 항목 | 기준 | 판정 |
|---|---|---|
| 케이던스 | 가민 대비 **±5 spm** | |
| **케이던스(주머니)** | **폰을 주머니에 넣고 달려도** 위와 같다 | |
| 평균 심박 | 가민 대비 ±3 bpm (워치/HC 연동 시) | |
| 최대 심박 | 값이 뜬다 | |
| 상승 고도 | 기압계 있으면 값, 없으면 `--`(0 이 아니다) | |

> '주머니' 칸이 따로 있는 이유: 2026-08-12 에 케이던스가 **1 spm** 으로 나왔다.
> `expo-sensors` 가 앱이 백그라운드로 가면 센서 구독을 떼기 때문이었다.
> 화면을 켜 놓고 달리면 멀쩡해서 **그 칸이 없으면 또 놓친다.**

### 폰 ↔ 워치

| 항목 | 기준 | 판정 |
|---|---|---|
| 폰에서 시작 → 워치도 시작 | 손목을 안 만져도 워치가 러닝에 들어간다 | |
| **폰에서 종료 → 워치도 종료** | **손목을 내린 채로** 폰에서 끝내도 워치가 끝난다 | |
| 기록이 **한 개**만 생긴다 | 워치 러닝이 따로 저장되지 않는다 | |
| 워치 지도 | 경로가 그려진다(2점짜리 직선이 아니다) | |
| 다음 러닝 거리 | **0.00 km 에서 시작**한다(지난 거리를 물려받지 않는다) | |

> '손목을 내린 채로'가 핵심이다. 워치 앱이 포그라운드면 `isReachable` 이 참이라 정지가
> 즉시 가고, 그러면 **버그가 안 보인다.** 실제 러닝은 손목을 내린 상태다.

### 저장 후

| 항목 | 기준 | 판정 |
|---|---|---|
| 유령 기록이 없다 | 0.0x km 짜리 기록이 안 생긴다 | |
| 신발 거리 차감 | 러닝 거리만큼 정확히 줄었다 | |
| 타임라인 | 심박 카드 탭 → 확대·스크럽이 된다 | |
| 스플릿 연동 | 구간 한 줄 탭 → 그 구간으로 확대된다 | |

> *"실기기에서 잰 숫자는 반드시 저장소에 적는다. 적히지 않은 측정은 없는 것과 같다."*

"안드로이드 실측은 한 번도 없다"로 방치됐다.
