## 1. App Privacy (앱 개인정보 보호)

애플은 각 항목을 **세 갈래**로 묻는다: 수집하는가 → 나에게 연결되는가(Linked) → 추적에 쓰는가(Tracking).

> **추적(Tracking)은 전부 '아니요'다.** 광고 SDK 가 없고 `NSUserTrackingUsageDescription`
> 도 선언하지 않았다(= ATT 팝업 없음). 광고 ID 도 수집하지 않는다.

| 데이터 종류 | 수집 | 사용자에 연결 | 추적 | 목적 |
|---|---|---|---|---|
| **정확한 위치** | 예 | 예 | **아니요** | 앱 기능 |
| **대략적인 위치** | 예 | 예 | **아니요** | 앱 기능 |
| 이메일 주소 | 예 | 예 | 아니요 | 앱 기능 |
| 이름 | 예 | 예 | 아니요 | 앱 기능 |
| 사용자 ID | 예 | 예 | 아니요 | 앱 기능, 분석 |
| 사진 | 예 | 예 | 아니요 | 앱 기능 |
| **건강 및 피트니스** | 예 | 예 | 아니요 | 앱 기능 |
| 제품 상호작용 | 예 | 예 | 아니요 | 분석 |
| 충돌 데이터 | 예 | 아니요 | 아니요 | 앱 기능 |
| 성능 데이터 | 예 | 아니요 | 아니요 | 분석 |
| 검색 기록 | 예 | **아니요** | 아니요 | 앱 기능 |

> 검색 기록이 '연결 안 됨'인 이유: 카탈로그에 없는 신발 검색어를 남길 때 **계정을 함께
> 보내지 않는다**(`ShoePicker.tsx`).

### 데이터를 판매하는가
**아니요.**

### 제3자와 공유하는가
**아니요.** 클라우드 저장 위탁(Google Firebase)은 애플 기준의 '공유'가 아니다.

## 2. HealthKit 사용 설명 (심사팀이 반드시 묻는다)

> 애플은 HealthKit 을 쓰는 앱에 **왜 필요한지**를 별도로 확인한다. 아래를 그대로 답한다.

**읽기(Read)**
- 심박수 — 러닝 중 심박을 표시하고, 저장 후 심박 존 분포·트레이닝 부하를 계산한다.
- 안정시 심박수 — 심박 존 계산(Karvonen)의 정확도를 높인다.

**쓰기(Write)**
- 워크아웃 — Keego 에서 기록한 러닝을 Apple 건강에 워크아웃으로 남겨,
  이용자의 활동 링과 다른 앱에서도 이어지게 한다.

**하지 않는 것**
- 건강 데이터를 광고·마케팅에 쓰지 않는다.
- 건강 데이터를 제3자에게 제공하지 않는다.
- 건강 데이터를 우리 서버로 보내지 않는다 — 심박은 이용자 기기와 이용자 본인의
  클라우드 백업(본인만 접근)에만 저장된다.

## 3. 위치 사용 설명

**언제 수집하는가**: 이용자가 **'러닝 시작'을 누른 동안에만**.
**왜 필요한가**: 거리·경로·페이스를 재고, 그 거리를 러닝화 누적에 더하기 위해.
**백그라운드**: 러닝 중 화면이 꺼져도 기록이 이어져야 하므로 백그라운드 위치를 쓴다.
이때 **잠금화면에 실시간 현황(Live Activity)** 이 떠 이용자가 기록 중임을 항상 안다.

권한 문구(Info.plist, 실제 값):
- `NSLocationWhenInUseUsageDescription` — "러닝 중 경로와 거리를 기록하기 위해 위치를 사용해요."
- `NSLocationAlwaysAndWhenInUseUsageDescription` — "화면을 꺼도 러닝 거리·경로를 계속 기록하려면 위치 권한이 필요해요."

## 4. 심사 메모 (App Review Notes)

> 심사자가 계정 없이 앱을 열면 로그인 화면에서 막힌다. **반드시 적는다.**

```
Keego 는 러닝 기록과 러닝화 수명 관리를 함께 다루는 앱입니다.

[로그인]
소셜 로그인(Apple / Google / Kakao / Naver)만 지원합니다.
Apple 로그인으로 바로 진입하실 수 있습니다.

[핵심 기능을 보시려면]
1. 로그인 후 온보딩에서 러닝화를 하나 등록합니다.
2. 홈에서 '러닝 시작'을 누르면 GPS 기록이 시작됩니다.
   - 실기기가 아니면 GPS 가 잡히지 않을 수 있습니다.
     시뮬레이터에서는 Debug > Location > City Run 을 사용해 주세요.
   - 실내에서 확인하실 경우 러닝 시작 화면의 '실내(트레드밀)' 를 켜면
     위치 없이 걸음수 기반으로 기록됩니다.
3. 러닝을 종료하면 기록이 저장되고, 그 거리가 선택한 러닝화에 자동으로 누적됩니다.

[위치 권한]
러닝을 시작한 동안에만 위치를 수집합니다. 러닝 중에는 잠금화면에
실시간 현황이 표시되어 이용자가 기록 중임을 항상 알 수 있습니다.

[건강 데이터]
Apple Watch 가 연결된 경우에만 심박이 표시됩니다. 없으면 '--' 로 표시되며
앱 사용에는 지장이 없습니다.

[계정 삭제]
마이 탭 > 설정 > 계정 삭제 에서 앱 안에서 바로 탈퇴할 수 있으며,
러닝·러닝화·사진이 모두 삭제됩니다.
```

## 6. 아직 정해지지 않은 것 — Support URL / 처리방침 URL

두 URL 은 **필수**이고 아직 없다. 선택지:

1. **GitHub Pages** — 저장소에 정적 페이지를 두고 공개. 무료·즉시.
   (과거 시도에서 404 가 났던 이력이 있으니 실제 접속을 확인해야 한다.)
2. **Notion 공개 페이지** — 가장 빠르다. 다만 도메인이 notion.site 라 신뢰도가 낮다.
3. **도메인 + 정적 호스팅** — 가장 반듯하다. 도메인 비용 발생.

**권한다: 1번**. 저장소에 이미 문서가 있어 관리가 한 곳에서 된다.
페이지 내용 초안은 `04-지원-페이지.md` 에 있다.
