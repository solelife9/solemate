### 4.1 Maps API 키 — 조치 완료

찾아보니 상태가 문서와 달랐다.

- 키는 `keego-620b8` 이 아니라 **`tough-processor-494601-b5`** 프로젝트 소유였다
  (`Maps Platform API Key`, uid `560a3296-…`). 결제 계정도 Firebase 와 **다르다**(01D2F3).
- **API 제한은 이미 걸려 있었다**(`maps-android-backend` 전용, 08-04 설정).
- **애플리케이션 제한이 없었다** — 즉 키를 주운 사람 누구나 쓸 수 있고 요금은 민우님에게 갔다.
  키는 `android/app/src/main/AndroidManifest.xml` 에 평문으로 있고 **저장소는 공개**다.

**건 조치**: 안드로이드 앱 제한 추가 — 패키지 `com.keego.app` +
업로드 키 SHA-1 `39:D4:…:67:CE` · 디버그 키 SHA-1 `5E:8F:…:F6:25`.
iOS 는 Apple 지도를 쓰므로(`Platform.OS === 'android'` 일 때만 Google) 영향 없다.

**남용은 없었다** — 최근 30일 Maps Android API 호출 **22회**, 전부 08-04~08-08
(민우님 테스트 시점)이다.

> ⚠️ **Play 업로드 후 반드시 할 일**: Play 가 앱을 **재서명**하므로 스토어 버전의
> SHA-1 은 위 둘과 다르다. **Play App Signing SHA-1 을 이 키에도 추가하지 않으면
> 스토어에서 받은 앱만 지도가 안 뜬다.** 로그인용 Firebase SHA-1 등록과 **같이** 처리한다.

| `94fe17ee…` | 2026-06-03 | ❌ **이 컴퓨터에 없다 — 행방 불명** |
| `986ea20f8d…` | 2026-07-31 | `~/Downloads/…-986ea20f8d.json` |

  키 파일 없이 ADC 만으로 프로덕션에 붙는 것을 **실제로 시험했다**.

### 출시일을 정하는 것

셋이 **동시에** 흐르고, 그중 가장 긴 것이 출시일이 된다.

| 흐름 | 길이 | 지금 시작할 수 있나 |
|---|---|---|
| **테스터 12명 × 14일**(개인 계정 확정) | **14일 +모집 기간** | **오늘 모집 시작하면 오늘부터** |
| Play 건강 데이터(Health Connect) 심사 | ⏳ 미상 — 콘솔에서만 확인 | 앱 업로드 후 |

**앞선 판단("방통위가 아니라 Play 건강 데이터 심사가 출시일을 정한다")을 고친다** —
개인 계정을 고른 이상 **테스터 12명 × 14일이 가장 앞에 있고, 유일하게 오늘 시작할 수 있다.**
스크린샷·피처 그래픽·서류는 그 14일 안에 끝나므로 임계 경로가 아니다.

⚠️ **모집이 늦어지는 만큼 출시가 그대로 밀린다.** 이 흐름만은 아무리 열심히 해도
줄일 수 없다 — 14일은 고정이고, 앞의 모집 기간만 민우님이 줄일 수 있다.

## 이 문서를 믿을 수 있는 이유와 없는 이유

**믿을 수 있는 것**: 코드·매니페스트·공개 페이지를 **직접 확인**하고 적었다.
GitHub Pages 200 응답, 처리방침 드리프트, 백그라운드 위치 제거 — 전부 실측이다.

**믿을 수 없는 것**: 콘솔 안쪽(Play 심사 기간, ASC 폼 상태)은 저장소 밖이라 모른다.
법적 판단(사업 해당 여부·유예 기산점)도 내가 답할 수 없다.
