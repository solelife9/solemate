
## 5. 🔴 출시일을 좌우하는 것 — 테스터 12명 × 14일 (**개인 계정 확정**)

**이것이 지금까지 찾은 것 중 출시일에 가장 크게 영향을 준다.**

2023년 11월 13일 이후에 만든 **개인 개발자 계정**은, 프로덕션 출시 신청 전에
**테스터 12명이 14일 연속 참여한 비공개 테스트**를 마쳐야 한다.

- 14일은 **12번째 테스터가 참여를 수락한 시점부터** 센다. 중간에 끊기면 다시 시작이다.
- **법인/조직(Organization) 계정에는 적용되지 않는다.** 단 조직 계정은 **D-U-N-S 번호**가 필요하고,
  그 발급에 다시 시간이 든다.
- **2026-08-15 민우님 확정: 개인 계정으로 간다.** 조직 계정의 D-U-N-S 대기(1~2주) 없이
  오늘 바로 14일 시계를 돌릴 수 있다는 것이 이유다. **계정 유형은 개설 후 못 바꾼다.**

| | 개인 계정 | 조직 계정 |
|---|---|---|
| 개설 | 즉시 | **D-U-N-S 발급 필요**(무료, 보통 1~2주) |
| 12명×14일 | **필요** | 불필요 |
| 사업자등록 | 불필요 | 필요 — **어차피 방통위 신고 때문에 하신다** |

> **어느 쪽이든 2주 안팎이 든다.** 다만 개인 계정의 2주는 **테스터 12명을 모아야** 흐르고,
> 조직 계정의 2주는 **서류만 기다리면** 흐른다.
> 민우님이 이미 사업자등록을 진행 중이므로 **조직 계정 쪽이 유리해 보이나**,
> D-U-N-S 실제 소요는 확인해 봐야 안다.

**어느 쪽을 고르든 베타 테스트는 하는 게 맞다** — 실기기 결함이 계속 나오고 있다.
모집 문구는 `06-베타-테스터-모집.md`.

## 6. 콘텐츠 등급 설문 (예상 답안)

| 질문 | 답 |
|---|---|
| 폭력 | 없음 |
| 성적 콘텐츠 | 없음 |
| 욕설 | 없음 |
| 약물·주류·담배 | 없음 |
| 도박·시뮬레이션 도박 | 없음 |
| 사용자 간 상호작용 | **예** — 공개 프로필·랭킹이 있다 |
| 위치 공유 | **아니요** — 이용자 간 위치 공유 기능이 없다 |
| 개인정보 공유 | **예** — 닉네임이 랭킹에 노출된다 |

→ 전체이용가 예상. **설문은 콘솔에서 직접 답해야 하며, '사용자 간 상호작용'을
빠뜨리면 등급 재산정 대상이 된다.** 신고·차단은 이미 구현돼 있다(`08-07 feat(소셜)`).
