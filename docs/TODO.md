  · 저장되면서 숫자가 **조용히 바뀐다**(본 것 ≠ 남는 것)
  · **폰 정확도를 영영 측정할 수 없다** — 워치를 차면 폰 값이 매번 덮인다

  **업계는 '기록자를 시작할 때 하나로 정한다'** — Apple 은 아이폰에 러닝 기록 기능 자체가
  없고(워치 전용), Garmin 도 시계가 기록자다. Strava 는 겹치는 활동이 오면 **병합이 아니라
  거부**한다. 두 기록자를 두고 사후에 필드별로 합치는 앱은 확인된 게 없다.

  | 안 | 내용 | 대가 |
  |---|---|---|
  | A | 폰 주도일 땐 워치가 **런을 안 보낸다**(심박만) | 폰 측정이 가능해지지만 **덜 정확한 값**이 남는다 |
  | **B (권장)** | 폰이 러닝 중에도 **워치 거리를 받아 쓴다**(진짜 미러링) | 심박 채널이 이미 있어 필드 추가 수준. 두 화면이 같아지고 저장 시 숫자가 안 바뀐다 |
  | C | 지금 유지 + **"워치 기록으로 보정했어요"** 한 줄 고지 | 가장 싸다. 정직해지지만 근본은 그대로 |

  ⚠️ **워치 워크아웃을 끄는 선택지는 없습니다** — watchOS 는 활성 워크아웃 세션이 있어야
