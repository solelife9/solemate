  - 금액은 월 $10~20 정도로 잡고 50%/90%/100% 알림이면 충분합니다
    (정상이면 사용자 1만 명에도 월 $4 수준입니다)

- [ ] **④ Google Maps 키 제한** — 지금은 **아무나 이 키로 지도를 쓰고 민우님께 청구**됩니다

  - Cloud Console → API 및 서비스 → 사용자 인증 정보 → 해당 키
  - **애플리케이션 제한**: Android 앱 → 패키지명 **`com.keego.app`** + SHA-1 `39:D4:…:67:CE`
  - **API 제한**: Maps SDK for Android 만 허용

  ⚠️ **패키지명 정정(2026-08-04).** 여기 `com.solemate` 로 적혀 있었다 — ②에서 앱 ID 를
  바꾸기 전에 쓴 값이다. 옛 이름으로 제한을 걸면 **제한이 걸린 채 지도가 죽는다**(키가
  거부되는데 원인은 콘솔 쪽이라 앱 로그만 봐서는 안 보인다). 반드시 `com.keego.app` 로.

  ℹ️ **안드로이드를 미루더라도 이건 지금 한다.** 이 키는 이미 저장소에 평문으로 들어가
  있고(Android Maps 키는 바이너리에 박힐 수밖에 없어 '숨기기'가 답이 아니다), 제한이
  없는 동안은 **누구든 이 키로 지도를 호출해 민우님께 청구**할 수 있다. iOS 는 Apple
  Maps 를 쓰므로 이 제한이 iOS 출시를 막지도, 깨뜨리지도 않는다.

- [ ] **⑤ App Check enforce 켜기** — 지금은 붙어만 있고 **실제 차단은 꺼져 있습니다**

  - ⚠️ 순서 지켜주세요. 먼저 켜면 아직 업데이트 안 한 사용자가 잠깁니다

- [ ] **⑥ 서비스 계정 키 정리** — 어제 받으신 키 **2개**가 아직 살아 있습니다
